# iliash.me — Personal Landing Page

Personal website and interactive engineering portfolio for **Iliash Hosain** ([iliash.me](https://iliash.me)), built with **React 19**, **Vite**, and a custom **Vanilla CSS Design Token System**.

## Features

- **Editorial Two-Theme System**: Adaptive Dark (`Obsidian Ink`) and Light (`Warm Paper`) themes with persistent preference and live token telemetry.
- **Interactive Project Sandboxes**: Inline interactive previews for `img2threejs`, `Showcase Suite`, `Mario-Kart-3.js`, `uinames`, and `Awesome AI Tools`.
- **Interactive Interface Lab**: Live kinematics/easing tester and optical typography token workbench with one-click CSS export.
- **Command Palette (`⌘K` / `Ctrl+K`)**: Keyboard-accessible navigation, theme switching, and direct project launching.
- **Quick Brief Composer**: Frictionless inquiry builder with one-click formatted brief copy or direct email launch.
